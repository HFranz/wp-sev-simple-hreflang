Before submitting to wp.org:

1. Open a real site with the plugin active, reproduce the panel shown in `screenshot-1-mockup.svg`.
2. Take an actual screenshot (PNG/JPG).
3. Save it as `screenshot-1.png` in the plugin's root directory (next to `readme.txt`) — that's the file wp.org's readme parser looks for, not this SVG.
4. Delete this `assets-mockup/` directory once done; it's not meant to ship.
